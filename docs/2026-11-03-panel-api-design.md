# Новая панель и REST API — дизайн

Дата: 2026-11-03. Статус: согласован пользователем 2026-11-03.

## Зачем

Панель `voiced` выглядит как типовая страница, и всё лежит одним столбцом: слова, громкость,
экран, ассистент, журнал. Пользователь хочет структуру и свежий вид. Позже будет мобильное
приложение, ему нужен стабильный API. Всё это не должно нагружать колонку: она слабая и
постоянно слушает микрофон, а задержки распознавателя недопустимы.

## Цели

- Панель в виде «Кольцо» (выбран пользователем) с разделами: частое сверху, редкое глубже.
- Работает с телефона и компьютера. Все текущие функции сохранены.
- REST API `/api/v1` с документом в `docs/api.md`. Панель и `setup` ходят только через него.
- Панель стоит CPU, только пока открыта и видима. Закрытая не стоит ничего.
- Открытая панель нагружает колонку меньше, чем сейчас. Цифры до и после сняты на колонке.

## Не цели

- Само мобильное приложение.
- Авторизация: **пользователь решил оставить доступ в локальной сети открытым**.
- Доступ снаружи домашней сети, HTTPS.
- Новые функции ассистента, обучения, экрана.

## Чего нельзя допустить

- Задержек в голосовом конвейере (`spotCommands`, KWS, Live) из-за HTTP.
- Сборки на колонке, фреймворков, внешних шрифтов и CDN: панель работает без интернета.
- Потери функции при переезде. Список функций ниже служит проверкой.

## Что мешает сейчас

Открытая вкладка каждые 300 мс запрашивает `/api/state`, `/api/led` и `/api/volume`, то есть
около 10 запросов в секунду. `/api/led` при этом ходит ещё и в `ledd`.

Хуже всего `state()`. Удерживая `d.mu`, он на каждое слово делает `Glob` и `Stat` по всем
ложным записям (`newFalses`). Та же `d.mu` нужна звуковому потоку в `process()` и в
`spotCommands`, поэтому диск напрямую задерживает звук. Устраняется в первую очередь.

## Нагрузка

1. **`state()` не трогает диск.** Счётчики ложных записей кешируются в памяти и пересчитываются
   при изменениях: разметка, удаление, обучение, старт демона.
2. **События вместо опроса.** Один общий хаб на всех клиентов, запущен только пока есть
   подписчик; без подписчиков нет ни горутины, ни таймера. Раз в секунду хаб собирает снимок и
   шлёт его, только если он изменился. Любое изменение через API будит хаб сразу.
3. **Живые показатели** (уровень, уверенность слов, состояние ассистента, громкость) идут 4 раза
   в секунду и считаются, только если подписчик попросил `?live=1`. Панель закрывает поток, когда
   вкладка скрыта.
4. **Медленный клиент не тормозит хаб:** запись с дедлайном, отставшие события отбрасываются,
   остаётся последнее. Подписчиков не больше 4, дальше ответ 503.
5. **Статика:** один встроенный `index.html`. Сжатие gzip и ETag считаются один раз при первом
   запросе, дальше ответ 304 или готовые байты.
6. **Экран и кольцо:** настройки `ledd` читаются при открытии раздела и после изменения, без опроса.

Замер: CPU `voiced` по `/proc/<pid>/stat` за одинаковые окна в 2 минуты, в тишине, без музыки.
Четыре точки: старая сборка без панели и с панелью, новая сборка без панели и с панелью. Для
новой сборки отдельно задержка блока звука, если её удастся снять без правки конвейера.
Цифры войдут в итоговый отчёт и в `docs/api.md`.

## Контракт API

База `/api/v1`, JSON в UTF-8. Частичные изменения идут через `PATCH`. Ошибки единообразны:

```json
{"error": {"code": "not_found", "message": "нет такого слова"}}
```

Коды: 400 неверный запрос, 403 запрос с чужого сайта, 404 нет ресурса, 409 конфликт состояния
(например, уже идёт запись), 500 внутренняя ошибка, 502 `ledd` не отвечает, 503 нет места
для подписчика. `code` стабилен и рассчитан на программу, `message` рассчитан на человека.
Совместимые добавления полей не меняют версию, несовместимые означают `/api/v2`. Клиент обязан
игнорировать незнакомые поля.

| Метод и путь | Что делает |
|---|---|
| `GET /info` | версия API, имя станции, что доступно; первый запрос после обнаружения |
| `GET /state` | снимок: звук, слова, запись, обучение, Gemini, настройки, ассистент, быстрые команды, громкость |
| `GET /events` (`?live=1`) | SSE: `state`, `hits` (при подключении и при изменении), `live` |
| `GET /hits` | срабатывания, новые первыми |
| `GET /hits/{id}/audio` | запись, `audio/wav` |
| `PUT /hits/{id}/verdict` | `{"verdict":"false"\|"ok"}` |
| `POST /hits/{id}/judge` | проверить через Gemini ещё раз |
| `PATCH /words/{id}` | `enabled`, `sensitivity`, `action` |
| `DELETE /words/{id}` | удалить слово |
| `POST /words/{id}/retrain` | переобучить |
| `POST /enroll` / `DELETE /enroll` | начать `{"name"}` / бросить запись слова |
| `POST /enroll/ambient` | записать фон, отвечает по окончании (8 с) |
| `POST /enroll/takes` | записать произнесение, отвечает по окончании |
| `GET /enroll/takes/{i\|last}` / `DELETE /enroll/takes/{i}` | прослушать / удалить |
| `POST /enroll/speech` | `{"seconds":20}`, отвечает по окончании |
| `POST /enroll/train` | `{"action"}`, начать обучение |
| `PATCH /settings` | `judge`, `judge_model`, `auto_false_undo`, `assistant{…}`, `quick{…}` |
| `GET /volume` / `PATCH /volume` | `{"volume","knob_step"}`; громкость можно менять шагом `{"step":±N}` |
| `POST /player/{pause\|play\|next\|prev}` | управление музыкой |
| `GET /led`, `PUT /led/settings`, `PUT /led/ai` | экран и кольцо, через `ledd` |
| `GET /record`, `POST /record` | отладочная запись |

Старые пути `/api/*` удаляются: их используют только панель и `setup`, и оба переезжают в этом
же изменении. `ledd` тоже переходит на `/api/v1/led` и общий вид ошибок, поэтому прокси `voiced`
остаётся простым и ничего не переводит.

**Защита от чужих сайтов.** Доступ в сети остаётся открытым, но браузер не должен давать случайному
сайту управлять колонкой. Запросы, меняющие состояние, с заголовком `Origin` другого хоста получают 403;
CORS не включается. Мобильное приложение и `setup` этот заголовок не шлют, поэтому их проверка не задевает.

## Поиск колонки

Свой короткий ответчик mDNS на стандартной библиотеке, без новых зависимостей: сервис
`_librestation._tcp`, порт 8780, в TXT `api=1`. Он только отвечает на запросы и ничего не рассылает
по таймеру. Если порт 5353 занят, это пишется в лог и панель работает дальше: адрес можно ввести
вручную. Проверка с Mac: `dns-sd -B _librestation._tcp`.

## Панель

Один файл, чистые HTML, CSS и JS, системные шрифты. Адрес раздела в `#`, поэтому работают назад и
закладки. Раздел отрисовывается из снимка; поля, которые сейчас редактируются, не перезаписываются.
Слева меню на компьютере, снизу на телефоне (от 720 px переключение). Тёмная тема основная, светлая
по настройке системы. Вместо `alert`, `prompt` и `confirm` встроенные сообщения и диалоги.

Куда уходят функции:

| Раздел | Содержимое |
|---|---|
| Главная | кольцо с громкостью (нажатия −/+) и состоянием, звук и его уровень, кнопки музыки, последнее срабатывание с «Ложное», статус ассистента и его последний ответ, быстрые команды общим переключателем |
| Слова | карточки слов: включение, чувствительность, действие, индикатор уверенности и порог, показатели, заметки обучения, «Дозаписать», «Переобучить», «Удалить»; мастер нового слова из 4 шагов с прослушиванием и удалением дублей; ход обучения |
| Журнал | все срабатывания: время, слово, источник, уверенность, музыка играла, статус, оценка Gemini, прослушать, разметка, «Ещё раз»; подсветка отменённых; пояснение, как работает разметка |
| Настройки | ассистент (модель, озвучка, голос, город, Spotify, Piper, ошибки); быстрые команды по группам; проверка Gemini (вкл, модель, очередь, авто-ложное); экран и кольцо (5 режимов, яркость, авто, показать режим ИИ); шаг кольца |

Отладочная запись `/record` остаётся только в API, как и сейчас: в текущей панели кнопки для неё нет.

Состояния, о которых панель должна сказать: нет связи (переподключается сама), нет звука, `ledd`
не отвечает, нет ключа Gemini, модель Яндекса не загружена, Spotify не привязан, идёт обучение,
нет слов и нет срабатываний (подсказка, что делать).

## Порядок работы

1. Снять замеры старой сборки.
2. Убрать диск из `state()`, сделать API, хаб и обновить тесты и `setup`, написать `docs/api.md`.
3. Сделать панель.
4. Сделать mDNS.
5. Выкатить на колонку, снять замеры, показать пользователю.

## Решения исполнителя, можно оспорить

- Фиолетовый акцент и тёмная тема как основная.
- mDNS для поиска, с ручным вводом как запасным путём.
- Добавлены управление громкостью и музыкой из панели и API: без них кольцо и мобилка были бы
  только показателем. Механизм уже есть (`Actuator`), конвейер не затрагивается.
- Снимок раз в секунду, живые показатели 4 раза в секунду.
- Защита от чужих сайтов через `Origin`, хотя в сети доступ открыт.
- Старые пути удаляются без периода совместимости.

## Готово, когда

Панель и API работают на колонке, `go test ./...` и `go vet` в `voice/` зелёные, `docs/api.md`
написан, цифры сняты, пользователь посмотрел панель на колонке.
